# Public

## Purpose

Defines the exported New-ISOFile function.

## Example contents

The existing New-ISOFile.ps1 implementation.

## Scope

Public files contain function definitions. The parent module loader discovers and exports their top-level function names.

## Dependencies

Requires Windows and the IMAPI2FS COM components. Boot media also uses ADODB.Stream. The function supports Windows PowerShell 5 and PowerShell 7.
